# Folder Aset Paslon & Media

Folder ini digunakan untuk menyimpan berkas foto pasangan calon atau aset grafis pemilihan OSIS.

### Cara Penggunaan:
1. Anda dapat meletakkan foto paslon langsung di sini, contoh:
   - `assets/candidates/paslon1.jpg`
   - `assets/candidates/paslon2.jpg`
   - `assets/candidates/paslon3.jpg`
2. Atau Anda dapat langsung mengunggah foto melalui **Panel Admin** pada menu **Pasangan Calon > Tambah / Edit Paslon**. Sistem akan otomatis mengompresi foto menjadi di bawah **100 KB**.
