PRODUCT REQUIREMENTS DOCUMENT
Aplikasi Pemilihan Ketua OSIS
SMPN 13 Penajam Paser Utara
Versi: 1.0
Target Eksekusi: Antigravity / AI Coding Agent
Batas Waktu Pemilu: Acara sekolah, ± 1 hari
________________________________________
1. Ringkasan Produk
Aplikasi web untuk pemilihan Ketua OSIS SMPN 13 Penajam Paser Utara secara online, digunakan oleh ± 400 siswa pemilih dari 10 laptop bersamaan, dengan panel admin, layar quick count real-time terpisah, dan dashboard analitik. Aplikasi harus ringan, stabil di koneksi sekolah, dan memiliki tampilan yang elegan dan profesional setara produk enterprise, bukan tampilan dekoratif bertema "AI generik".
________________________________________
2. Tujuan dan Metrik Keberhasilan
Tujuan	Metrik
Pemungutan suara cepat & anti-double	0 duplikasi suara; 1 NISN = 1 suara
Admin dapat mengelola paslon & pemilih mandiri	Import CSV 400 baris < 5 detik
Hasil transparan	Quick count akurat, latensi < 5 detik
Analisis pasca-pemilu	Laporan partisipasi per kelas, per paslon, tren per jam
Ringan untuk 10 laptop concurrent	Beban < 100 KB per halaman (non-analytics)
________________________________________
3. Pengguna dan Peran
Pemilih (Siswa) — anonim. Hanya perlu NISN. Tidak ada login, tidak ada akun. Satu NISN hanya bisa memilih sekali.
Admin (Guru) — satu akun. Login hanya dengan sandi guru13. Akses penuh ke kontrol pemilu, data paslon, data pemilih, quick count, dan analitik.
Tidak ada role lain. Tidak ada registrasi publik.

5. Skema Database dan API
5.1 Tabel
text
election_config   (id=1, is_open, admin_password bcrypt, election_title, started_at, closed_at, updated_at)
candidates        (id, number, name, chairman, vice_chairman, photo_url, vision, mission, created_at)
voters            (id, nisn UNIQUE, name, class, has_voted, voted_at, created_at)
votes             (id, candidate_id FK, voter_nisn FK, voted_at)
admin_sessions    (token UUID PK, created_at, expires_at)
5.2 RPC Endpoints
Semua endpoint mengembalikan bentuk { ok: boolean, data?: any, error?: string }.
Publik (tanpa token admin):
•	check_nisn(p_nisn text) — verifikasi NISN ada, belum memilih, pemilu sedang dibuka
•	get_candidates() — daftar paslon untuk halaman voting
•	cast_vote(p_nisn text, p_candidate_id bigint) — transaksional; lock row voter; tolak jika sudah memilih
Admin (butuh p_token uuid):
•	admin_login(p_password text) — return token sesi, berlaku 8 jam
•	admin_get_config, admin_toggle_election(p_open)
•	admin_get_candidates, admin_save_candidate, admin_delete_candidate
•	admin_import_voters(p_voters json), admin_get_voters(p_limit, p_offset, p_search), admin_delete_voter
•	admin_reset_votes — hapus semua suara dan reset status pemilih
•	admin_quick_count — data agregat ringan untuk polling
•	admin_analytics — data agregat lengkap untuk dashboard
5.3 Aturan Integritas
•	Password admin di-hash dengan crypt(p, gen_salt('bf')).
•	cast_vote menggunakan SELECT ... FOR UPDATE pada row voter untuk mencegah race condition.
•	Semua tabel mengaktifkan Row Level Security tanpa policy = akses langsung via anon key ditolak. Hanya RPC yang berjalan.

6. Design System
Prinsip desain: Tenang, rapi, terstruktur. Tidak ada dekorasi tanpa fungsi. Tidak ada emoji. Tidak ada gradient meriah. Tampilan mengikuti konvensi dashboard institusional, bukan landing page SaaS.
6.1 Palet Warna
Nama	Hex	Penggunaan
Papaya Whip	#fdf0d5	Latar utama (voting & admin), card background contrast
Deep Space Blue	#003049	Teks utama, header admin, grafik
Molten Lava	#780000	Judul utama, aksen kuat, warning
Brick Red	#c1121f	Tombol primary, badge state, leader highlight
Steel Blue	#669bbc	Tombol secondary, garis bantu, chart series
Aturan warna: Setiap halaman hanya boleh menggunakan maksimal 3 warna dari palet secara bersamaan (di luar teks). Tidak boleh membuat gradient multi-warna. Background tidak boleh lebih dari satu radial gradient tipis (opacity < 0.1).
6.2 Tipografi
•	Display & heading: Fraunces (Google Fonts), weight 600–700, letter-spacing -0.02em. Memberi karakter editorial dan premium.
•	Body & UI: Inter (Google Fonts), weight 400–600.
•	Angka besar (quick count, stat card): Fraunces tabular variant atau Inter weight 700 dengan font-feature-settings: "tnum".
Skala:
•	Display: 48px / line-height 1.1
•	H1: 32px / 1.2
•	H2: 24px / 1.3
•	H3: 18px / 1.4
•	Body: 16px / 1.6
•	Small: 14px / 1.5
•	Micro: 12px / 1.4, uppercase, letter-spacing 0.08em
6.3 Spasi dan Layout
•	Grid 4px base: 4, 8, 12, 16, 24, 32, 48, 64.
•	Container max-width: 1120px (admin, analytics), 960px (voting NISN), full-bleed (quick count).
•	Padding halaman: 24px mobile, 48px desktop.
6.4 Komponen Dasar
Tombol
•	Primary: background #c1121f, teks putih, radius 8px, padding 12/24, weight 600, tanpa shadow default. Hover: background #780000. Active: transform: scale(0.98).
•	Secondary: border 1px #003049 pada latar transparan, teks #003049. Hover: background #003049, teks putih.
•	Ghost: tanpa border, teks #003049 underline saat hover.
•	Danger: background #780000, teks putih.
Card
•	Background putih, border 1px #e7dfce, radius 12px, padding 24px, tanpa shadow default. Hanya gunakan shadow tipis (0 1px 2px rgba(0,48,73,0.06)) atau tanpa sama sekali.
Input
•	Border 1px #d6cdb8, radius 8px, padding 12/16, background putih. Focus: border #669bbc 2px, tanpa glow.
Badge status
•	Bentuk persegi (radius 4px), padding 2/8, teks 12px uppercase tracking 0.05em.
•	"Sudah memilih": background #e8f4ec, teks #1e6b3a.
•	"Belum memilih": background #f4e8e8, teks #780000.
6.5 Motion
•	Durasi standar: 200ms untuk micro-interaction, 300ms untuk transisi halaman.
•	Easing: cubic-bezier(0.22, 1, 0.36, 1) untuk masuk, ease-out untuk keluar.
•	Animasi diperbolehkan: fade-in card dengan stagger 40ms, transisi slide halaman voting, hover translate 2px pada card paslon, progress bar quick count yang bertransisi lebar.
•	Dilarang: bounce, shake, pulse, glow, confetti, animated gradient, animated background, loading spinner dekoratif, animated emoji/SVG.
6.6 Yang Harus Dihindari (Anti AI-Slop)
Instruksi eksplisit untuk coding agent:
•	Tidak ada emoji di mana pun — tidak di tombol, tidak di judul, tidak di toast, tidak di empty state. Gunakan teks biasa atau ikon SVG garis 1.5px monokrom jika benar-benar perlu.
•	Tidak ada gradient di tombol, card, atau badge.
•	Tidak ada glassmorphism, backdrop-blur, atau frosted glass.
•	Tidak ada shadow bertumpuk (multi-layer). Maksimal satu shadow tipis.
•	Tidak ada icon library penuh (FontAwesome, Heroicons full set) — hanya SVG inline untuk ikon esensial.
•	Tidak ada ilustrasi dekoratif, blob SVG, atau pattern background.
•	Tidak ada animasi pada scroll.
•	Tidak ada "hero section" bertingkat dengan CTA ganda di halaman voting.
•	Tidak ada copywriting berlebihan seperti "Selamat datang di masa depan pemilihan!" — gunakan bahasa netral formal.
•	Border radius konsisten (8px untuk input, 12px untuk card, 999px untuk badge bulat). Jangan campur radius acak.
•	Konsisten warna: jangan menambahkan warna di luar palet meski hanya untuk status/error. Error gunakan #780000, success gunakan hijau gelap #1e6b3a (satu-satunya pengecualian).

10. Keamanan
•	Password admin hanya disimpan sebagai bcrypt hash di database.
•	Anon key Supabase boleh terekspos di frontend (normal untuk Supabase) karena semua akses dikontrol RPC + RLS deny-all.
•	Token admin disimpan di sessionStorage, dihapus saat tab ditutup atau tombol "Keluar".
•	RPC admin memvalidasi token lewat helper _is_admin(p_token) sebelum aksi.
•	cast_vote mencegah double vote dengan SELECT ... FOR UPDATE.
•	NISN tidak di-log ke console di production.

11. Deployment
1.	Buat repo GitHub publik: osis-smpn13.
2.	Upload semua file. Aktifkan GitHub Pages (branch main, root).
3.	Buat proyek Supabase, jalankan SQL schema lewat SQL Editor.
4.	Isi js/config.js dengan SUPABASE_URL dan SUPABASE_ANON_KEY.
5.	Commit ulang. Akses via https://{username}.github.io/osis-smpn13/.
6.	Untuk mengganti sandi admin: jalankan SQL UPDATE election_config SET admin_password = crypt('sandiBaru', gen_salt('bf')) WHERE id = 1;.

14. Catatan untuk Coding Agent
•	Prioritas utama: fungsionalitas dan keandalan di atas estetika. Estetika harus dicapai melalui tipografi, spasi, dan hirarki — bukan dekorasi.
•	Rujuk Design System Bagian 6 setiap kali membuat komponen. Jangan improvisasi warna, radius, atau shadow.
•	Rujuk Bagian 6.6 setiap kali tergoda menambahkan elemen visual. Jika ragu, hapus.
•	Bahasa Indonesia formal. Hindari kata "yuk", "sih", "banget", atau tanda seru ganda.
•	Konsisten bentuk respons RPC. Selalu cek data.ok sebelum menggunakan data.data.
•	Uji dengan data dummy minimal: 5 paslon, 400 pemilih tersebar di 12 kelas, 200 suara masuk. Pastikan tidak ada error console di seluruh halaman.
